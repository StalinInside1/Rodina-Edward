## О проекте

Здесь публикуются сборки лаунчера Rodina Edward. APK лаунчера скачивается со страницы [Releases](https://github.com/StalinInside1/Rodina-Edward/releases/latest).

Официальный сайт Rodina RP: **[rodina-rp.com](https://rodina-rp.com)**. Оригинальную игру и сведения о ней получайте на официальном сайте.

## Установка

1. Откройте [последний релиз](https://github.com/StalinInside1/Rodina-Edward/releases/latest).
2. Скачайте APK из раздела **Assets**.
3. Откройте скачанный файл на Android и подтвердите установку, если система попросит разрешение.

Если GitHub временно недоступен, откройте [страницу репозитория](https://github.com/StalinInside1/Rodina-Edward) и выберите **Releases**.
